# Приложение «Ты где был?!#»

Приложение для контроля местоположений, имеет следующие основные функциональные возможности:

- периодическая запись местоположений вручную или по расписанию с выбранными днями и временем;
- ожидание получения местоположений с заданной точностью;
- отображение всей истории местоположений на карте в виде маркеров;
- сохранение данных в локальной базе данных устройства при отсутствии подключения к сети и выгрузка на сервер при его появлении;
- возможность поделиться уникальной ссылкой для отслеживания своего местоположения c другими лицами (например отслеживание родителями местоположений детей ) в браузере на любом устройстве. Ссылка вида https://kol.hhos.ru/gkk/map.php?interval=15&wm=uniq_string , содержащая саму уникальную для пользователя строку и интервал обновления данных в секундах;
- Наблюдающий через бот может перейти по ссылке вида https://kol.hhos.ru/gkk/map.php?nid=string2&wm=uniq_string , где может настроить геообласти контроля — при посещении этих областей, наблюдателю придет уведомление от бота;
- регистрация при помощи telegram-бота. Также в боте есть возможность сформировать уникальную ссылку для просмотра своих местоположений; удаление всех своих данных;
- возможность работы в оффлайн-режиме — данные хранятся только на устройстве, а также онлайн — история местоположений хранится на серверной части(их можно просмотреть по уникальной ссылке);
- локальная история хранится на устройстве; перед отправкой координаты преобразуются по действующему серверному протоколу.

Подробное описание - https://kol.hhos.ru/2022/12/07/%d0%bf%d1%80%d0%b8%d0%bb%d0%be%d0%b6%d0%b5%d0%bd%d0%b8%d0%b5-%d1%82%d1%8b-%d0%b3%d0%b4%d0%b5-%d0%b1%d1%8b%d0%bb/.

## Сборка проекта

Текущая конфигурация рассчитана на Android Studio с поддержкой **AGP 8.11.0**:
JDK 17, Gradle 8.13 через wrapper, compileSdk 36, minSdk 24 и targetSdk 34.
Kotlin 2.2.21, KSP 2.2.21-2.0.4 и Hilt 2.58 согласованы с этой версией AGP.
Версии Android-зависимостей находятся в `gradle/libs.versions.toml`, выбранные зависимости — в lock-файлах.
Зависимости локальной карты закреплены в `feature/map/web/package.json` и `package-lock.json`.

Открывать корень проекта и использовать Gradle wrapper. Для проверки из терминала:

```sh
./gradlew :domain:test testDebugUnitTest :app:assembleDebug lintDebug
```

На Windows используется `gradlew.bat`. Путь к установленному Android SDK задаётся
локально через Android Studio/`local.properties`.

## Структура проекта

- `:domain` — Kotlin/JVM: модели, отдельные контракты истории, настроек, сессии,
  авторизации и управления записью; сценарии использования и TrackingCoordinator. Android, LiveData,
  Room и HTTP-типы в этот модуль не входят.
- `:data` — Android library: Room, сетевой API, сохранение настроек и сессии,
  сбор координат, синхронизация и Hilt-привязки реализаций. Зависит от `:domain`.
- `:app` — сборка приложения и Hilt-зависимостей, корневая навигация Decompose,
  тема Material 3, foreground service, receivers и планировщик в `tracking`.
- `:feature:settings` — расписание, параметры замера, доступ к геолокации и выбор темы.
- `:feature:profile` — вход, подтверждение учётной записи, выход и отправка ссылки.
- `:feature:map` — выбранный день, локальная карта OpenLayers в WebView через AndroidView и нативные элементы управления.
- `:feature:about` — сведения о приложении и лицензии библиотек.

Feature-модули зависят от `:domain`, но не от `:app`, `:data` или друг от друга.
`RootFactory` связывает реализации в приложении; состояние и действия экранов принадлежат
компонентам Decompose. Вкладки сохраняют компоненты, StateKeeper сохраняет выбранную
вкладку, дату и видимость слоёв карты, черновик настроек и ввод кода при восстановлении процесса.

История, настройки, сессия и состояние экранов предоставляются через Flow/StateFlow.
Экраны Compose подписываются на состояние с учётом жизненного цикла. Действия передаются
через Intent; компоненты обновляют StateFlow. Запросы компонентов отменяются при их уничтожении.
Принятые изменения настроек завершаются в очереди приложения при закрытии экрана.
Моменты времени в доменных моделях представлены `java.time.Instant`, время расписания —
`LocalTime`, выбранный день карты — `LocalDate`; календарные границы рассчитываются с `ZoneId`.
Монотонное время замера хранится отдельно. Room и DataStore сохраняют прежние форматы,
а адаптеры сервера и карты формируют прежние JSON-строки. Поле `datetime` передаётся строкой
без преобразований. Для системного шаблона даты уведомления используется совместимый
`SimpleDateFormat` только в Android-адаптере. Для minSdk 24 подключён core library desugaring.

Настройки хранятся в Preferences DataStore. Профиль с JWT хранится отдельно, зашифрован ключом Android Keystore
и исключён из backup. История хранится в Room (схема v4).

Геолокация использует системный LocationManager через AndroidX Compat. Обязательных
Google Play Services нет. GPS работает без сети при точном разрешении; сетевой
провайдер зависит от устройства и может отсутствовать. Приблизительное разрешение
поддерживается при доступном сетевом провайдере. Отказ в разрешении и выключенная
геолокация не закрывают приложение и не блокируют историю/настройки.

Разрешения запрашиваются при ручном запуске или включении расписания. Фоновый доступ
и разрешение точных будильников нужны для обоих периодических режимов;
уведомления запрашиваются отдельно, отказ не блокирует допустимую foreground-сессию.
Каждый следующий замер назначается через setAlarmClock до получения координат и
отправки данных. Сессия записи и время следующего замера сохраняются в DataStore.
При открытии приложения внутри включённого расписания запись возобновляется.
При включённом расписании ручная запись также ограничена его периодом; поддерживаются ночные интервалы.
Частота замеров зависит от ограничений Android и прошивки устройства.

Тестовые APK для проверок Room собираются командой
`./gradlew :data:assembleDebugAndroidTest`; это не запускает тесты на устройстве.
Этот же APK содержит проверки Android Keystore и сохранения сессии с Android FileStorage.
Локальные JVM-тесты хранилища используют переносимый OkioStorage с настоящими DataStore
и PreferencesSerializer; интеграцию платформенного хранилища проверяют instrumentation-тесты.

Схема Room v4 сохраняет историю при миграции с v3 и привязывает точки к профилю.
Отправка выполняется пакетами; WorkManager сохраняет задания с требованием сети
и повторяет синхронизацию независимо от службы сбора координат.
Числовые параметры измерения сохраняются кнопкой «Применить параметры».
Проверки Room/SQLite запускаются на JVM через Robolectric и используют общий набор
сценариев с instrumentation-тестами.

## Оформление и лицензии

Material 3 использует отдельные светлую и тёмную палитры с бирюзовым акцентом.
Режимы «Как на устройстве», «Светлая» и «Тёмная» сохраняются в DataStore.
На широком экране навигация находится сбоку, на узком — снизу.
Оболочка OpenLayers, JS/CSS и маркеры включены в APK. История передаётся из Room;
без сети доступны точки, кластеры, линия трека и круг точности. Только подложка
загружается с OpenFreeMap без API-ключа. Её сбой не блокирует локальную историю; доступен повтор.
Кнопки Compose показывают весь трек, последнюю точку, слои и текущее местоположение.
Скрытие предыдущих точек убирает их кластеры, сохраняя последнюю точку выбранного дня.
Слои переключаются независимо. Цвета векторных объектов и элементов управления
следуют эффективной теме приложения, как и подложка: Positron для светлой темы, Dark для тёмной.
Стили и значки подложки включены в APK; смена темы сохраняет камеру и выбор точек.
Инструкции по сборке JS и браузерным тестам: [feature/map/web](feature/map/web/README.md).

«О приложении → Библиотеки и лицензии» показывает каталог AboutLibraries,
сформированный при сборке для соответствующего варианта приложения, включая OpenLayers
и библиотеки, вошедшие в локальную JS-сборку.
Метаданные и полные тексты лицензий включены в APK и читаются без интернета.

Compose BOM 2026.03.00 и Lifecycle 2.10.0 совместимы с AGP 8.11.0/compileSdk 36.
Используются Decompose 3.5.0 и AboutLibraries 13.1.0.
Тесты проверяют контраст палитр, восстановление состояния и навигацию, а также
редактирование настроек и обе темы с увеличенным шрифтом через Compose/Robolectric.
