# Локальная карта whereMe

Все файлы карты принадлежат модулю `:feature:map`. Исходники JS находятся в `web/src`; HTML, `bootstrap.js` и CSS приложения хранятся только в `src/main/assets/map`. Скрипт сборки создаёт там `map.bundle.js` из исходников JS и OpenLayers, копирует `ol.css` и формирует лицензии. OpenLayers, адаптер стилей и их зависимости закреплены в `package-lock.json`. Готовые assets включаются в APK; Gradle не требует Node.js для обычной Android-сборки.

После изменения web-исходников:

```sh
cd feature/map/web
npm ci
npm run build
npx playwright install chromium
npm test
```

`map.bundle.js`, `ol.css` и метаданные лицензий генерируются — их не редактируют вручную. Изменение HTML/CSS/`bootstrap.js` не требует пересборки JS. Каталог `aboutlibraries` подключён к общему экрану лицензий приложения. В коммит входят исходники, lockfile, собранные assets и метаданные лицензий. `node_modules` не включается.

Для тестов можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE` с путём к установленному Chromium. Тесты подменяют запросы тайлов и не обращаются к реальному серверу подложки. Они проверяют JS в настольном Chromium; Android-мост отдельно проверяется instrumentation-тестами.

Перед браузерными тестами автоматически выполняется `npm run check`: собранный JS, CSS OpenLayers и лицензии сравниваются с результатом сборки в памяти. Если assets устарели, проверка завершается ошибкой и просит выполнить `npm run build`; сами файлы при проверке не меняются.

Карта получает историю, видимость слоёв и тему через `whereMeMap` из Kotlin. События ready/failed/selection/tiles возвращаются через `Android.postMessage`. Публичные методы не обращаются к БД или API приложения. Последняя точка хранится отдельно от предыдущих и не входит в их кластеры.

Маркеры рисуются векторными SVG из `src/marker-icons.js`: круг — предыдущая точка, пин — последняя; знак паузы обозначает стоянку. Цвет центра последней точки отражает точность: зелёный до 100 м включительно, янтарный до 500 м включительно, красный выше 500 м. Контур и фон маркеров следуют цветам темы приложения. Отдельные PNG и загрузка изображений маркеров по сети не нужны.

Подложка — векторные тайлы OpenFreeMap: `https://tiles.openfreemap.org/planet/latest/{z}/{x}/{y}.pbf`, без API-ключа, с видимой атрибуцией OpenFreeMap, OpenMapTiles и OpenStreetMap. Адаптер `ol-mapbox-style` применяет Positron в светлой теме и Dark в тёмной. Два слоя используют один источник тайлов; переключение сохраняет камеру, историю, выбор и видимость пользовательских слоёв. Kotlin передаёт эффективную тему приложения явно, включая ручной выбор в настройках.

Снимки стилей от 22.10.2026 находятся в `web/src/styles` и включаются в bundle. Спрайты из `https://tiles.openfreemap.org/sprites/ofm_f384/ofm` сохранены в assets в обычном и двойном разрешении. Из стилей удалены неиспользуемый источник Natural Earth и PBF-шрифты; Noto Sans заменён системным sans-serif с сохранением начертания. У Dark повышен контраст подписей, дорог и зданий. Сетевые шрифты и внешние стили не загружаются. Лицензии исходных стилей находятся рядом с JSON; сборка включает их в notices и общий экран лицензий.

Офлайн-пакетов тайлов и предварительного скачивания нет; применяется обычное HTTP-кеширование WebView. Код, маркеры, линия и круг точности доступны без сети. Обновление версии браузерных зависимостей требует повторной проверки поддерживаемых Android WebView.
